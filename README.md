## ⚡ Tech Stack & Architecture (Awwwards & Unseen.co Standard)

- **Three.js (WebGL)** — Real-time 3D interactive particle storm & dual-spiral vortex (5,500+ particles) with mouse inertia and auto-pause on scroll for solid 60fps performance.
- **GSAP 3 + ScrollTrigger** — Pinned horizontal gallery deck, word-by-word scroll text illumination, and spring micro-interactions.
- **Lenis 1.1** — Buttery inertia scroll synchronization with GSAP ticker.
- **Web Audio API** — 4-Stem interactive party synthesizer (128 BPM Sub Kick, Acid Arp, 16th Hi-Hats, Reverb Pad) with real-time HTML5 `<canvas>` oscilloscope waveform spectrum.
- **Emil Kowalski Tactile Craft** — Synthesized Web Audio haptic clicks for buttons, sliders, card flips, and toggles.
- **Dynamic 3D Holographic Shader** — Obsidian RFID Pass customizer with real-time gyro/mouse tilt, iridescent specular foil sheen, dynamic SVG QR code generator, and 3D card flip.
- **Canvas API** — 60fps throttled 35mm club film grain simulation with quick toggle.
- **Tailwind CSS & Google Fonts** — `Syne 800`, `Cinzel`, `Anton`, `Oswald`, `Cormorant Garamond`, `Plus Jakarta Sans`, and `JetBrains Mono`.

## 🌐 How to Run Locally

You can launch a local HTTP server inside the `socialeuphoria` folder:

```bash
# Python
python -m http.server 4321 --directory socialeuphoria

# Or Node.js
npx serve socialeuphoria
```

Open `http://localhost:4321` in any modern desktop or mobile browser.
