## ⚡ Tech Stack

- **Three.js** — 3D neon particle vortex hero (5000 particles)
- **GSAP + ScrollTrigger** — Scroll-driven animations, pinned horizontal gallery
- **Lenis** — Buttery smooth scrolling
- **Vanilla CSS** — Glassmorphism, neon gradients, responsive design
- **Canvas API** — Real-time film grain overlay
- **Web Audio API** — Ambient sound toggle

## 🚀 Features

- Cinematic 0→100 loader with neon glow
- Interactive Three.js particle vortex (mouse-reactive)
- Word-by-word scroll text reveal
- Animated stat counters
- Horizontal scroll event gallery (pinned)
- Previous events carousel with Instagram reel links
- Glassmorphism rule cards with stagger reveals
- Custom cursor with hover labels
- Film grain overlay
- Sound equalizer toggle
- Fully responsive with mobile hamburger menu
